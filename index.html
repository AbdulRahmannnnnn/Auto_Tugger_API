Serve this page over HTTP

This page was opened straight from the file system (file://), so the browser blocks it from reading openapi.yaml. Start a static server from the same folder, then open the address it prints: 

npx serve .
# or
python3 -m http.server 8080

The specification could not be loaded

Check that openapi.yaml sits in the same folder as index.html and is reachable from the server that is running.
